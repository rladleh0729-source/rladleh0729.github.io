기본 실행과 사용 흐름

버전에 따라 세부 UI와 기능은 다를 수 있지만, 기본적인 사용 흐름은 아래와 같이 정리할 수 있다.

1. 실행

  1. 다운로드 페이지에서 원하는 버전을 받는다.
  2. 압축 파일이라면 먼저 압축을 푼다.
  3. 실행 파일을 열어 프로그램을 시작한다.

2. 기본 입력

텍스트 입력창에 질문이나 명령을 입력하고 전송하면 응답을 받는 구조를 기본으로 한다.

예시 입력: 안녕 / 오늘 할 일 정리해줘 / 25*16 / sqrt(144)

3. 계산성 입력

계산이나 수학 관련 입력은 일반 대화와 다르게 별도 처리되도록 확장할 수 있다. 실제 지원 범위는 버전별로 다를 수 있다.

예시 입력: 2+3*4 / log(100) / ln(2) / sqrt(81)

4. 참고

  • 개발 중인 버전은 응답이 항상 일정하지 않을 수 있다.
  • 입력 형식에 따라 기능 지원 여부가 달라질 수 있다.
  • 정확한 변경 사항은 업데이트 페이지에서 확인하는 것이 좋다.
